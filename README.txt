KOMPETENZMODELL ZYKLUS 3 – IPHONE WEB-APP

Dateien:
- index.html
- styles.css
- app.js
- data.js
- manifest.webmanifest
- service-worker.js
- icons/

Verwendung:
1. Den gesamten Ordner auf einen HTTPS-Webserver laden (z.B. GitHub Pages, Netlify, Vercel oder einen bestehenden Schul-Webserver).
2. Die Seite auf dem iPhone in Safari öffnen.
3. Teilen > Zum Home-Bildschirm.
4. Die App funktioniert danach auch offline, sobald sie einmal vollständig geladen wurde.

Die Navigation:
Hauptbereich > Teilkompetenz > Kompetenzbeschreibung > Indikatoren

Hinweis:
Eine PWA kann auf dem iPhone nicht direkt aus einer ZIP-Datei installiert werden. Sie muss zuerst über HTTPS erreichbar sein.


HOCHLADEN:
- Lade den gesamten Inhalt der ZIP-Datei in dein GitHub-Pages-Repository hoch.
- Wichtig: alle bisherigen Dateien ersetzen.
- Die Datei index.html muss im Hauptverzeichnis liegen.
- Der Ordner icons muss vollständig mit hochgeladen werden.
